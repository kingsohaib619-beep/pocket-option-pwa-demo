# PO Bot Pro Demo PWA

Mobile-first PWA inspired by a trading bot dashboard.

## Important
This starter is **Demo/Paper Trading only**. The SSID field is a UI placeholder for an account connection layer; no Pocket Option API or SSID extraction is included. Do not commit real SSIDs, passwords, cookies, or session tokens to GitHub.

## Run locally
```bash
npm install
npm run dev
```
Open http://localhost:3000

## Deploy
Works well with Vercel/Netlify/other Node hosts. Import this repository, install dependencies, and deploy.
